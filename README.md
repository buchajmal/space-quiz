# Orbit Quiz

A self-contained space exploration quiz. Answer 10 questions, track your score, and see your mission results.

## Run

Open `index.html` directly in a modern web browser. No server, build step, or dependencies are required.

## Features

- Ten multiple-choice questions with explanations
- Progress bar and live score
- Animated correct and incorrect answer feedback
- Results screen with a score-based emoji reaction and replay
- Responsive layout, light/dark color-scheme support, and reduced-motion support
